# Lesson 1: Creating IT Documentation with AI

**Program:** Per Scholas — AI Skills for IT Support  
**Project:** Aperta IT Help Desk — VPN Setup Documentation  
**Status:** Completed guided practice; knowledge-base article held for revision

## Project Overview

In this lesson, I practiced using ChatGPT to create and review technical documentation for an IT help desk. The objective was to draft a staff-facing knowledge-base article that was accurate, easy to follow, and aligned with an established documentation style guide.

## Scenario

A remote employee was unable to access the staff intranet because their Windows laptop did not have a VPN connection configured.

The support ticket documented how the VPN connection was created using Windows' built-in VPN settings.

My task was to turn those resolution notes into clear instructions for staff members.

## Tools Used

- ChatGPT Projects
- Aperta knowledge-base style guide
- Windows VPN configuration instructions
- IT support ticket resolution notes
- AI-assisted drafting and verification

## Work Completed

1. Set up an Aperta IT help desk project in ChatGPT.
2. Added the knowledge-base style guide to the project.
3. Prepared a documentation specification identifying the audience, task, required steps, and success state.
4. Used ChatGPT to draft the VPN knowledge-base article.
5. Reviewed AI-generated assumptions and verification points.
6. Conducted a simulated reader test.
7. Evaluated whether the article was ready for publication.

## Issue Identified

During the simulated reader test, the reader became stuck at Step 7 because the instructions did not clearly explain how to identify the correct VPN server address in the IT welcome email.

This demonstrated that an article can appear complete but still contain instructions that are unclear to the intended reader.

## Decision and Resolution

I chose to **hold the article for revision** rather than approve it for publication.

The VPN server address instructions required clarification and verification before the article could be released to staff.

## Skills Demonstrated

## Lessons Learned

AI can accelerate IT documentation, but its output must be checked against reliable sources. A list of AI-generated assumptions does not replace reviewing the entire article.

I also learned that simulated reader testing helps identify confusing instructions, while actual screen verification is needed to confirm technical accuracy.
